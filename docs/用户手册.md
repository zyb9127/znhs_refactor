## 一、背景与人群

### 1.1 背景

营销话术智能体通过 **「配置驱动 + 大模型生成」**，将各省接口数据标准化后生成个性化营销话术。

- 一个「智能话术配置」= **省份 + 场景分类**
- 无需改代码，配置发布后即可上线

### 1.2 面向人群

| 人群 | 职责 |
|------|------|
| 技术支撑 | 提供接口文档、排查接口问题、部署运维 |
| 运营人员 | 在管理页配置智能话术配置、话术模板、测试发布 |

> **权限说明**：鉴权模式下，账号只能编辑所属省份配置；其它省份为「查看」只读。本部账号拥有全部省份权限。

## 二、配置前准备

数据有两种来源，二选一即可：

- **透传模式（推荐）**：调用方（CTI / 坐席系统）已持有用户/产品数据，放在请求的 `extra_info` 传入，本服务不再调外部接口。无需接口文档，配置最简单。
- **接口查询模式**：由本服务调用外部接口获取数据，需要接口文档（含 URL、请求参数、**请求头**、成功响应示例）。

### 2.1 准备接口文档（仅接口查询模式需要）

至少需要一个核心接口，返回：

- `current_package`：当前套餐
- `recommended_packages`：推荐产品列表

接口文档需包含：接口名称、URL、请求方式、请求参数、**请求头（如渠道标识）**、**成功响应示例 JSON**。

> 例：北京查询接口需带请求头 `x-Channel-ID: ngbusi`（见第八章）。

### 2.2 准备话术文案

话术内容格式：固定文案 + `{变量}` 占位符。支持整块域，也支持字典**子字段**精确引用：

```text
您好！您当前套餐为{cur_brief}，根据您近6个月使用情况{usage_line}。
我为您推荐{pkg_brief}套餐，{diff_str}。
```

子字段示例（透传字典 / 标准域均可）：

```text
为您推荐 {extra_info[final_recommendations][recommend_package_name]}，
当前套餐 {extra_info[current_package][package_name]}。
```

### 2.3 话术模板字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 场景分类名称 | 是 | 模板标识，如「套餐推荐话术_5G升档」 |
| 应用环节 | 按需 | 如 `切入环节` / `推荐环节` |
| 应用场景 | 否 | 如 `流量超套` |
| 产品 ID | 否 | 留空 = 兜底模板；多个用英文逗号或换行分隔 |
| 话术内容 | 是 | 含 `{变量}` 或 `{域[子键]}` 占位符 |
| 关联变量 | 按需 | 系统按占位符自动推荐勾选 |
| 状态 | 是 | `online` / `offline` |

> 产品 ID / 应用环节 / 应用场景 至少填写一项。

## 四、创建智能话术配置流程

### 4.1 进入创建页面

点击顶部 **「创建新配置」**：

![创建智能话术配置页面](./用户手册图片/sandbox/07_创建Skill.png)

> 二级页左上角提供 **「返回上一级」**，可随时回到管理列表。

### 4.2 填写基本信息

| 字段 | 填写说明 |
|------|---------|
| 目标省份 | 覆盖全国 31 省，下拉选择（不可手动输入）；非本部账号锁定为本省 |
| **场景分类** | 如 `套餐推荐`。**填写后即时校验**：同省下若 ES/运行时已存在同名场景分类，输入框报错并禁用后续按钮 |
| 描述 / 版本 / 负责人 | 按需填写 |

> 重名校验前移到第一步，**最后一步不再做重名拦截**。同名场景分类在不同省份可各自独立存在。

### 4.3 两种创建路径

**路径 A · 快速创建（推荐先建骨架）**

1. 填好省份 + 场景分类（名称可用）
2. 点击 **「⚡ 快速创建（暂不配置接口 / 话术，稍后再补）」**
3. 系统直接发布骨架并自动热重载，跳转编辑页补配接口与话术

**路径 B · 完整配置后发布**

1. 省份 + 场景分类填写完成后，进入与「编辑」一致的编辑器（两个 Tab：**接口配置**、**话术模板**）
2. 配置接口与话术（均可留空，稍后补配）
3. 点击 **「下一步：生成预览 →」** → **「下一步：去发布 →」** → **「确认发布」**

### 4.4 发布说明

- 发布后**自动热重载**生效，无需勾选
- **不支持覆盖**已有同名配置；重名须改「场景分类」名称
- 创建流程已去掉「跑通校验」强制步骤，接口/话术可后续补配

## 五、配置智能话术配置

在管理列表点击 **「编辑」**，打开编辑弹窗，共两个 Tab：**接口配置**、**话术模板**。

![编辑智能话术配置 - 接口配置](./用户手册图片/sandbox/02_编辑Skill_接口配置.png)

### 5.1 接口配置

#### 5.1.1 接口列表

「接口配置」Tab 展示已配置的接口节点，每行操作：**映射结果 | 编辑 | 智能映射 | 删除**。

- **映射结果**：查看该接口经映射后写入的 7 大标准数据域取值
- **智能映射**：粘贴响应样例，AI 自动生成映射规则

#### 5.1.2 新建接口

点击 **「+ 新建接口」** 进入分步编辑弹窗。

#### 5.1.3 选择数据来源

第①步选择数据来源，**默认「透传模式」（推荐）**：

| 模式 | 说明 | 何时使用 |
|------|------|---------|
| **透传模式（extra_info）· 推荐** | 不调外部接口，调用方在 `extra_info` 传入数据 | 调用方已持有数据（首选） |
| 接口查询模式 | 由本服务调外部接口获取数据 | 需要服务实时查询外部系统 |

透传模式下还有两种**映射方式**：

| 映射方式 | 说明 |
|----------|------|
| **直接透传字段 · 推荐** | `extra_info` 字段按原名作为话术上下文；第②步勾选要暴露的透传字段 |
| 智能映射到标准域 | 把 `extra_info` 映射进 7 大标准域；不配映射时，与标准域同名的顶层 key 自动透传 |

![编辑接口 - 配置请求](./用户手册图片/sandbox/10_编辑接口_配置请求.png)

#### 5.1.4 透传模式：配置要点

- **第①步 基本信息**：节点名称、描述、映射方式
- **第②步 透传字段 / 域映射**：
  - 直接透传：粘贴 `extra_info` 样例 → 勾选要暴露的字段（不勾 = 全部顶层字段）
  - 智能映射：粘贴样例 → 智能分析 → 映射到 7 大标准域
- 话术模板里用 `{字段名}` 引用；若字段是字典，可展开选子字段 `{字段[子键]}`（见 5.2）

#### 5.1.5 接口查询模式：三步配置

- **第①步 配置请求**：接口名称、URL、请求方法、**请求模板**、**请求头**
  - 请求模板支持 `{{PHONE}}`、`{{INTENT}}`、`{{PROVINCE}}`、`{{extra_data.xxx}}`
  - **请求头**：键值对增删；运行时在默认 `Content-Type` / `Accept` 之上叠加（同名以此处为准）
  - 省侧常需渠道头，例如北京：`x-Channel-ID` = `ngbusi`
- **第②步 响应样例**：粘贴成功响应 JSON；接口未就绪可开启「模拟」开关

![编辑接口 - 响应样例](./用户手册图片/sandbox/11_编辑接口_Mock数据.png)

- **第③步 出参映射**：把响应字段映射到标准数据域

![编辑接口 - 出参映射](./用户手册图片/sandbox/12_编辑接口_出参映射.png)

映射分两步：

| 步骤 | 作用 |
|------|------|
| `response_extract` | 按 JSON 路径整块取数（如 `raw_tags`、`current_package`、`recommended_packages`） |
| `field_transform` | 字段筛选（保留/排除）、单位换算、重命名后写入标准域 |

`response_extract` 示例：

```json
{
  "raw_tags": "bean.tags",
  "current_package": "bean.mainoffer",
  "recommended_packages": "bean.recommend_results"
}
```

`field_transform` 示例：

```json
{
  "usage.data_usage": {
    "from": "raw_tags",
    "type": "filter_include",
    "include_keys": ["近3月平均流量(MB)", "近6月平均流量(MB)"],
    "unit_convert": {
      "近3月平均流量(MB)": "mb_to_gb"
    }
  },
  "tags": {
    "from": "raw_tags",
    "type": "filter_exclude",
    "exclude_keys": ["近3月平均流量(MB)", "近6月平均流量(MB)"]
  }
}
```

> **注意**：`response_extract` 保存时整字典替换。若智能分析漏掉某标准域（如 `recommended_packages`），系统会自动保留旧映射，避免生产事故。确需删除时将该 key 显式置为 `""`。

#### 5.1.6 智能自动映射

点击接口的 **「智能映射」**：

![智能映射弹窗 - 空](./用户手册图片/sandbox/13_智能映射弹窗_空.png)

粘贴响应 JSON 并点击 **「智能分析」**：

![智能映射弹窗 - 分析结果](./用户手册图片/sandbox/14_智能映射弹窗_分析结果.png)

系统自动生成映射规则，检查右侧数据域结果后点击 **「应用并保存」**。

### 5.2 话术模板

点击 **「话术模板」** Tab：

![编辑智能话术配置 - 话术模板](./用户手册图片/sandbox/03_编辑Skill_话术模板.png)

#### 5.2.1 添加模板

点击 **「+ 添加模板」**：

![新建话术模板 - 上半部分](./用户手册图片/sandbox/15_新建话术模板_上半部分.png)

填写基础信息：

| 字段 | 说明 |
|------|------|
| 场景分类名称 | 模板标识（必填） |
| 产品 ID | 多个用逗号/换行分隔；留空 = 兜底 |
| 应用环节 | 如 `推荐环节` |
| 应用场景 | 如 `流量超套` |

#### 5.2.2 关联接口与插入占位符

「① 关联接口」勾选数据来源后，「可映射固定域」出现可拖入的变量标签：

- **接口查询 / 标准域**：显示映射产出的域（如 `current_package`、`usage`）
- **透传模式**：显示透传字段（绿标签）；未显式选字段时提示「透传全部顶层入参字段」
- **带 ▾ 的字段可展开**：选择字典下一级子字段，插入精确占位符，如 `{extra_info[current_package][package_name]}`

```text
您好！您当前套餐为{cur_brief}，根据您近6个月使用情况{usage_line}。
我为您推荐{pkg_brief}套餐，{diff_str}。
```

#### 5.2.3 话术要求（可选预设）

「话术要求」提供 `标准` / `精简` / `严谨合规` 预设，一键套用。建议话术字数控制在 **150 字以内**。

#### 5.2.4 关联变量

系统检测到占位符后会自动推荐并勾选对应变量：

![新建话术模板 - 变量推荐](./用户手册图片/sandbox/17_新建话术模板_变量推荐.png)

#### 5.2.5 常用变量

| 变量 | 来源 |
|------|------|
| `cur_brief` / `current_package` | 当前套餐 |
| `pkg_brief` | 推荐产品（单条格式化） |
| `diff_str` | 套餐差异（系统计算；无值则可不写） |
| `pkg_fee` / `pkg_flow` / `pkg_voice` | 推荐套餐月费/流量/语音（计算生成；无值不注入） |
| `usage_line` / `usage` | 历史用量 |
| `user_tags` / `tags` | 用户标签 |
| `extra_info` | 透传/主服务补充信息（可展子字段） |
| `table` | 差异表格（仅前端展示，不打入大模型） |

#### 5.2.6 CSV 批量导入

点击 **「导入 CSV」** 批量导入，列顺序：

```text
场景分类名称,环节,意图,产品ID,话术内容,关联变量(可留空),状态(online/offline)
```

导入为追加，不覆盖已有模板。请使用 UTF-8（带 BOM）以免 Excel 乱码。

## 七、发布上线

### 7.1 发布

在管理列表点击 **「发布」**，或创建流程最后一步确认发布：

- **自动热重载**：发布后即时生效，无需额外勾选
- **不覆盖同名**：同省同场景分类已存在时，须改名后发布
- 发布后配置进入「已发布」状态，可被话术调度引擎调用

### 7.2 下线与删除

- **下线**：已发布配置点击「下线」；下线后不再被调度
- **删除**：已发布需先下线再删除；删除后列表**立即刷新**

### 7.3 配置修复（自愈）

列表 **「修复」** 按钮：基于 ES **当前配置**重新校验，发现缺失映射（如 `raw_tags`、`recommended_packages`）时，用配置内线索（`field_transform` / `mock_response`）自动生成修正并发布回 ES。无需依赖本地标准文件。

### 7.4 状态流转

```
编辑中 →（发布）→ 已发布 →（下线）→ 已下线 →（删除）
```

> 已发布配置保存改动后需重新发布才能在线上生效（配合热重载）。

## 八、实际例子：北京套餐推荐

### 8.1 配置信息

| 字段 | 值 |
|------|-----|
| 省份 | `beijing` |
| 场景分类 | `套餐推荐` |
| 数据来源 | 接口查询模式 |

### 8.2 接口配置

接口 `北京测试接口_api` 核心配置（含请求头，与现网一致）：

```json
{
  "url": "http://restapi.ngcrmpfcore-bj.cs.bj.cmos:8080/ngcrmpfcore_bj/csf/business/productRecommend",
  "method": "POST",
  "headers": {
    "Content-Type": "application/json",
    "x-Channel-ID": "ngbusi"
  },
  "request_body_wrapper": "params",
  "request_template": {
    "ioId": "",
    "intent": "{{INTENT}}",
    "phone": "{{PHONE}}",
    "currentMainOffer": {
      "curOfferName": "{{extra_data.currentMainOffer.curOfferName}}",
      "curOfferId": "{{extra_data.currentMainOffer.curOfferId}}",
      "curOfferFee": "{{extra_data.currentMainOffer.curOfferFee}}"
    }
  },
  "response_extract": {
    "raw_tags": "bean.tags",
    "current_package": "bean.mainoffer",
    "recommended_packages": "bean.recommend_results"
  },
  "field_transform": {
    "usage.data_usage": {

      "type": "filter_include",
      "include_keys": ["近3月平均流量(MB）", "近6月平均流量(MB）"],

      "type": "filter_exclude",
      "exclude_keys": ["近3月平均流量(MB）", "近6月平均流量(MB）"]
    }
  }

```

## 九、技术原理简述

```
POST /marketing/recommend
    ↓
智能话术配置运行时（province + 场景分类）
    ↓
MarketingPipeline 三步管道
    ├── Step1 DataStep：调接口（带 headers）/ 读 extra_info → 映射到标准域或透传字段
    ├── Step2 RecommendStep：筛选 TopN 推荐产品
    └── Step3 ScriptStep：匹配模板 → 填槽（含 {域[子键]}）→ LLM 生成话术
```

## 十、对外接口说明

### 10.1 实时推荐主接口

```
POST /znhs/marketing/recommend
```

#### 入参

| 字段 | 必填 | 说明 |
|------|------|------|
| phone | 是 | 手机号 |
| intent | 是 | 场景分类（业务意图） |
| province | 是 | 省份代码（如 `beijing`；广东可传数字编码 `200`，服务端自动转 `guangdong`） |

### 10.2 常见错误码

| 状态码 | 含义 | 处理 |
|--------|------|------|
| 404 | 未找到配置 | 检查 province/intent，确认已发布 |
| 409 | 同名配置已存在 | 修改场景分类名称后重新发布 |
| 500 | 内部异常 | 检查接口配置、映射、LLM 服务；可点「修复」 |
| 504 | 接口超时 | 检查外部接口或调大 timeout；核对请求头是否齐全 |

### 11.2 常见问题

**Q：话术中变量为空？**  
A：检查接口是否返回字段 → 出参映射是否写入标准域 → 话术模板是否勾选变量。透传模式确认已勾选透传字段，子字段用 `{域[子键]}` 精确引用。可用「映射结果」核对。

**Q：上线后未生效？**  
A：发布后默认自动热重载。若仍未生效，手动调用 `/api/skills/reload`，或确认配置来源为 ES（非仅本地旧文件）。

**Q：无法删除配置？**  
A：已发布配置需先下线再删除。

**Q：只能查看不能编辑其它省份？**  
A：鉴权模式下账号只能编辑本省配置。跨省请用本部账号。

**Q：创建时报「已存在同名配置」？**  
A：同省场景分类不可重复。在第一步「场景分类」改名；不再提供覆盖选项。

**Q：接口查询省侧报鉴权/渠道错误？**  
A：在「编辑接口 → 配置请求 → 请求头」补全省侧要求的头（如北京 `x-Channel-ID: ngbusi`）。

**Q：推荐只剩 1 条兜底、当前套餐被当成推荐？**  
A：多为 `recommended_packages` 映射丢失。点列表「修复」，或检查 `response_extract` 是否含 `recommended_packages`。

**Q：透传字段看不到下一级参数？**  
A：在话术模板「可映射固定域」点带 ▾ 的标签展开子字段；样例 JSON 需声明字段结构（值可为空骨架）。
